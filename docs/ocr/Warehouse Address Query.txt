Warehouse Address Query
POST API path:/b2b-overseas-api/vl/buyer/warehouse/query-address/vl
# Update Log
Date Details
08/28/2025 New interface added
#® Use Case
Query the GIGA warehouse addresses by warehouse code, including Seller-owned warehouses. Warehouse codes can be obtained via the Inventory Query interface.
# Rate Limiting Rule
20 requests per 10 seconds
#® Header Parameters
Parameter Name Data Type Required ? Description Default Value
Content-Type string true application/json
timestamp string true The time is converted to milliseconds, the number of seconds that have passed since January 1, 1970 (UTC). Only
requests within 20 minutes are processed.
nonce string true 10-digit random
sign string true Signature
client-id string true Open API account applied by user
#® Query Parameters
None
# Request Body Parameters
Parameter Name Data Type Required ? Description Default Value
warehouseCodes string[] true GIGA warehouse code. Max 200 warehouse codes per query, ans use comma (,) to separate multiple entries
® Example Request
{
"warehouseCodes": |
"CA3"
]
}
# Response Parameters
Parameter Name Data Type Required ? Description Default Value
success boolean true Indicates whether the request was successful
code string true Error code. Both successful and failed requests will include this response.
data array false Response data
warehouseCode string false GIGA warehouse code
address string false Warehouse address
country string false The country where the warehouse is located
state string false The state where the warehouse is located
city string false The city where the warehouse is located
zipCode string false The Zip Code of the warehouse address
requestld string true The unique identifier of the request.
msg string false Error message. The content may be blank for secondary errors.
subMsg string false Detailed error message description.
recommend string false Error Diagnostics URL
