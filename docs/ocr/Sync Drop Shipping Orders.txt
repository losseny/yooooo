Sync Drop Shipping Orders
POST API path:/b2b-overseas-api/v1l/buyer/order/dropShip-sync/vl
# Update Log
Date Details
08/28/2025 New interface added
09/04/2025 The [hasOtherLabel] field was added to indicate the labeling requirements for labels (except for Brand Label and Packing Slip)
12/11/2025 The recipient info fields (including: shipName, shipPhone, shipAddress1, shipAddress2, shipCity, shipCountry, shipState, and shipZipCode) must not contain Chinese characters or Arabic Script.
05/14/2026 For DE/UK Marketplace, shipPhone is now restricted to 6-15 digits.
05/28/2026 The currencyCode field was added to indicate the currency of order amount and product price.
08/27/2026 Added support for CAN Marketplace Buyers to import Drop Shipping orders via this interface.
#® Use Case
Sync Drop Shipping orders to GIGAB2B.
