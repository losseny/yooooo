Inventory Query
POST API path:/b2b-overseas-api/v1l/buyer/inventory/quantity/v2
# Update Log
Date Details
09/11/2025 New interface added
01/08/2026 Query is restricted to the products in Buyer's Saved Items List or products with stockpiled inventory.
01/10/2026 For DE/UK Self-arranged Shipping Buyers, querying inventory by warehouse is available.
09/10/2026 For US Drop Shipping Buyers, querying Sellers inventory by warehouse is available. The value is returned via the sellerinventoryDistribution field.
10/22/2026 Querying shared inventory is supported. For details, see the totalSharedinventory and sharedinventory field descriptions.
#® Use Case
Query product's available inventory or Buyer-owned inventory on GIGAB2B by SKU. Product promotional inventory and storage fee are also available for query.
For US/DE/UK Self-arranged Shipping Buyers, querying inventory by warehouse is available.
Note: Only the products in Buyer's Saved Items List or products with stockpiled inventory can be accessed.
# Rate Limiting Rule
10 requests per 10 seconds
