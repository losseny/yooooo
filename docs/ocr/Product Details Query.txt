# Update Log
Date Details
08/28/2025 New interface added
12/18/2025 The toBePublished field was renamed to skuAvailable as a product availability flag, returning "true" if the product is available, or "false" otherwise.
04/16/2026 The brand, material and main color of products and the protection service rate can be queried. For details, please refer to the new fields: brandinfo, mainMaterial, mainColor, and protectionServiceRates.
04/21/2026 The afterSalesPolicy field was added to return the URL for After-sales Policy details.
05/21/2026 The productVideoUrl field was added to return the URL of the product showcase video. The isLGP field was added on the DE Marketplace to indicate whether the product has an LGP badge.
07/02/2026 The assembledLengthUnit and assembledWeightUnit fields were added to return the length and weight units for the assembled product.
07/16/2026 The returnRate field was added to return the product-level RMA rate.
08/27/2026 The categoryPath field was added to return the full path of category, and the associateProductinfo array was added to return itemCode and name for variants.
09/17/2026 1. For DE Marketplace Drop Shipping Buyers, the remoteAreaPostalCodes array was added to return the remote area postal code (shipToPostCodes) for the shipToCountry, based on the shipFromCountry. 2. For DE/UK Marketplace
Self-arranged Shipping Buyers, the isMsf field was added to indicate whether the product is eligible for the MSF program.
#® Use Case
Query product details by SKU (Item Code) or product name. Only the products in Buyer's Saved Items List or products with stockpiled inventory can be accessed.
# Rate Limiting Rule
20 requests per 10 seconds
#® Header Parameters
Parameter Name Data Type Required ? Description Default Value
Content-Type string true application/json
timestamp string true The time is converted to milliseconds, the number of seconds that have passed since January 1, 1970 (UTC). Only
requests within 20 minutes are processed.
nonce string true 10-digit random
sign string true Signature
client-id string true Open API account applied by user
#® Query Parameters
None
# Request Body Parameters
Parameter Name Data Type Required ? Description Default Value
skus string[] false The list of SKU. The number of SKUs cannot exceed 200.Exactly one of the skus and productNames fields must be
provided as the request parameter.
productNames string[] false The list of productName. The number of productNames cannot exceed 200. The number of SKUs cannot exceed
200.Exactly one of the skus and productNames fields must be provided as the request parameter.
