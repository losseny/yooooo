Shipping Info Query
POST API path:/b2b-overseas-api/vl/buyer/order/track-no/vl
# Update Log
Date Details
08/28/2025 New interface added
08/06/2026 An object field [shipFromInfo] was added at the tracking number level, providing the ship-from address information with two sub-fields, country and warehouseCode, which represent the ship-from country and the shipping warehouse
respectively.
08/15/2026 New field [warehouseArea] added at the tracking number level to indicate the shipping warehouse area.
#® Use Case
Query the shipping information of orders, including package-level tracking numbers and carriers. For the DE Marketplace, return tracking numbers are also available for query.
# Rate Limiting Rule
20 requests per 10 seconds
