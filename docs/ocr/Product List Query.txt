#® Use Case
Query the product list on GIGAB2B. Only the products in Buyer's Saved Items List or products with stockpiled inventory can be accessed.
# Rate Limiting Rule
10 requests per 10 seconds
#® Header Parameters
Parameter Name Data Type Required ? Description Default Value
Content-Type string true application/json
timestamp string true The time is converted to milliseconds, the number of seconds that have passed since January 1, 1970 (UTC). Only
requests within 20 minutes are processed.
nonce string true 10-digit random
sign string true Signature
client-id string true Open API account applied by user
#® Query Parameters
None
# Request Body Parameters
Parameter Name Data Type Required ? Description Default Value
page integer false Page number, no smaller than 1. The calculation rule for the range of returned orders is: from pageSize*(page-1)+1 to
pageSize*page. For example, if page=10 and pageSize=100, then the orders returned on page 10 are from the 901st
to the 1000th. By default, it starts from the first page.
pageSize integer false The size of each page, indicating the number of order lines included in each page. Min 100 order lines and max 10000
order lines.The default value is 5,000 when left blank.
sort integer false Product sorting by: 1:updatTime:asc; 2:updatTime:desc; 3:datePosted:asc; 4:datePosted:desc
firstArrivalDate string false The date when the product's first batch of inventory arrived at the warehouse. Format: yyyy-MM-dd. Example: if
firstArrivalDate=A, then products with First Arrival Date no earlier than A will be returned.
lastUpdatedAfter string false When this field is filled, query the SKU with updateTime later than the filled time; No limit when left blank.
queryTimeType integer false Supported queryTimeType: 1 - Last update time: will invalidate the lastUpdatedAfter request parameter if selected. 2 -
Added time: The latest time when a product was added to My Saved Items. Note: startTime/endTime must be provided
after the queryTimeType is selected, and vice versa.
startTime string false Format: yyyy-MM-dd HH:mm:ss. Default time zone: UTC-8. Note: This field must be provided with both endTime and
queryTimeType fields together; otherwise, it becomes invalid.
endTime string false Defining a time range with startTime. Format: yyyy-MM-dd HH:mm:ss. Default time zone: UTC-8. Note: This field must
be provided with both startTime and queryTimeType fields together; otherwise, it becomes invalid.
