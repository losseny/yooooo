Product Price Query
POST API path:/b2b-overseas-api/v1l/buyer/product/price/vl
# Update Log
Date Details
08/28/2025 New interface added
01/08/2026 Query is restricted to the products in Buyer's Saved Items List or products with stockpiled inventory.
01/15/2026 1. The logic for the price, exclusivePrice, and discountedPrice fields was optimized. 2. New fields added: purchaseLimit, srpPrice, limit, promotionFrom (within the spotPrice array), and promotionTo (within the spotPrice array). Refer to
each field's description for its specific use case.
04/02/2026 The internationalFulfillmentFees field was added to return Pan-European fulfillment fee for products in the UK/DE Marketplace.
05/14/2026 The exclusivePriceExpireTime was added to return the expiration time of the exclusive price set for the corresponding product.
07/30/2026 For products on the DE Marketplace, the remoteShippingFee field was added to return the fulfillment fee for shipments to domestic remote areas, and the remotelntlFulfillmentFee field for Pan-European remote areas.
08/20/2026 In the rebatesPrice array, the minRebatePrice and maxRebatePrice fields will be removed, and the rebateAmount and rebatePrice fields will be added. The data structure will be adjusted to return rebate prices by tier.
#® Use Case
Query product prices by SKU.
Note: Only the products in Buyer's Saved Items List or products with stockpiled inventory can be accessed.
# Rate Limiting Rule
10 requests per 10 seconds
